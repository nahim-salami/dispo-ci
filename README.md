# dispo-ci

Exécuteur d'intégration continue. **Ce dépôt ne contient aucun code source.**

Chaque exécution, lancée à la main, récupère le code d'un dépôt privé avec une clé en lecture seule, le vérifie (analyse, types, tests, construction, contrôle dans un navigateur) et n'affiche publiquement que le résultat de chaque étape. Les journaux détaillés et les captures sont chiffrés avant d'être joints.
